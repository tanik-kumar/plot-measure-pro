# Examples

This folder contains small repo-safe example files for understanding PlotMeasure Pro project format.

Files included:

- `sample-project.plotmeasure.json`

Notes:

- The sample project JSON is intended as a format example.
- It references a placeholder PDF path and will need to be edited before loading in the app on another machine.
- Real cadastral or revisional map PDFs are not bundled in this public repo.
