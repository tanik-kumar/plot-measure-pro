# Changelog

All notable changes to this project are documented in this file.

The format follows Keep a Changelog and versioning in this repo starts from `v1.0.0`.

## [1.0.0] - 2026-03-22

### Added

- Native macOS land-measurement app built with `SwiftUI` and `PDFKit`
- PDF import, page navigation, zoom, pan, and rotation
- Calibration by manual distance, scale ratio, map scale, and scale bar
- Distance, path, and polygon measurement workflows
- Polygon editing with drag, insert, delete, and undo/redo
- OCR-assisted scale suggestions
- Edge-snapping support for scanned maps
- Export to annotated PDF, CSV, and JSON
- Bihar and India-focused area-unit presets such as `decimal`, `bigha`, `kattha`, and `dhur`
- Versioned `v1.0.0` GitHub release with packaged macOS app zip
